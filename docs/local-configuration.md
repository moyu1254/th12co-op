# PCごとの設定とオンラインの共通条件

Rules 5 / Protocol 4ではMOD用コピーの `th12.cfg` を各PCの設定元とする。「ゲーム設定」で画面方式・解像度・BGM・効果音の音量を保存し、「入力設定」で各プレイヤーのキーとパッドを保存する。原作のインストール先にある設定・スコアは更新しない。

オンラインを開始すると、固定テンプレート `profiles/th12-online.cfg` にローカル項目だけを反映し、セッション専用のフォルダーへ書き出す。終了時はローカル項目だけをMOD用コピーへ戻す。オフライン側のフレームスキップ・ショット長押し低速などを、オンラインの共通値で上書きしない。自動テストでは設定を戻さない。

## 照合した原作仕様

TH12の設定は60バイトで先頭の識別子が `0x00120001`。通常版1.00aの `Supervisor::load_game_config` は `0x42fe90`、設定本体は `0x4ceab0`。初期化は `0x423230`。通常版1.00bはコードに `+0x20`、グローバルのアドレスは共通。既存の[版比較](version-layout-audit.md)と所有バイナリの逆アセンブルを照合した。

| ファイル位置 | 扱い | 根拠・意味 |
|---|---|---|
| `04–19` | ローカル | 原作の入力割当・軸しきい値。読込時に入力設定へ転送 |
| `1a–1d` | ローカル | 描画／BGM方式／効果音／画面方式。原作の範囲検査も維持 |
| `1d` | ローカル | `0` 全画面、`1` 640×480、`2` 960×720、`3` 1280×960。`0x450ad0`以降のウィンドウ生成を確認 |
| `20–21` | ローカル | BGM・効果音の音量、0–100。`0x453ced/0x453cfa`とオプションメニューの利用箇所を確認 |
| `28–2f` | ローカル | ウィンドウ座標。`0x450bfc/0x450c0c`で使用 |
| `38`の32bit値の`0x100`だけ | ローカル | 起動時の画面方式ダイアログ。`0x44f636`、`0x4518f1`で確認 |
| その他 | 共通 | 固定テンプレートを使用。`1e`のスキップ、`22`のリプレイ関連動作、`0x200`のショット長押し低速、未分類領域を含む |

設定全体の一致を通信の条件にすると、音量・解像度が異なるPC間で接続できなくなる。そのため、ローカル領域だけをゼロ化してから求めたSHA-256を `AssetProfile.Configuration` として照合する。共通領域は照合の対象に含め、必ずテンプレート値へ正規化する。準備後のファイルが各PC自身の設定スナップショットと完全に一致することも、別途検証する。

入力は各PCでデバイスから操作ビットへ変換した後、確定フレームに載せる。相手のデバイス番号・キー設定・音量は通信しない。Rules 5の機体選択は接続後のゲーム内画面で行い、確定入力とネイティブの状態ダイジェストで同期する。

## 開放条件

既存の `coop_progression` のメニュー判定パッチを継続利用する。Extra全装備とPractice全6面の利用可否をメモリ内で変更し、スコアファイルを偽造しない。オンライン用コピーにはスコア・リプレイを持ち込まないため、元のクリア記録が異なっても同じ選択肢から始められる。オフラインの既存スコアはそのまま保持する。

## 検証

自己テストはローカル項目の異なる設定の共通ハッシュ一致、共通・未知項目の正規化、設定範囲検査、オフライン設定の保持、スコア・リプレイの除外、元スコアの不変性を確認する。実ゲーム・描画方式・別PC/WAN・物理パッドの実測範囲は[検証結果](../verification/RESULTS.md)で区別する。

## 設定画面の停止修正

旧 `GameSettingsForm` のコンストラクターはUIスレッドで `ReadLocal(...).GetAwaiter().GetResult()` を実行していた。ファイルI/Oが非同期完了した場合、`ReadLocal` の継続も同じWindows Formsコンテキストへ戻ろうとするため、画面を作る前に相互待機になる。

呼出元の非同期イベントで読込を完了してから、バイト列を受け取るコンストラクターへ渡す。保存も非同期を保ち、再読込して変更対象だけをマージする。STAの実メッセージループ上で読込・フォーム生成・変更・保存・再生成、同時に更新された他項目の保持を自己テストする。オフライン設定の保持とオンライン用マージ・終了時の保存は既存の実ファイル/TLS自己テストで確認する。
