# TH12 CO-OP v0.1.0（協力ルール2）

最初のGitHub配布版です。通常版1.00a・通常版1.00b・Steam版1.00bで、2人が別々の自機を操作できます。

## ダウンロードと起動

Assetsの `TH12COOP-Lockstep-Windows.zip` を展開し、`Start.cmd` を開いてください。オフライン専用の入口は `Offline.cmd` です。GitHubが生成する「Source code」には実行用バイナリを含みません。

両者に対応する原作のコピーが必要です。原作データは同梱していません。Steam版では、原作を所有するアカウントでSteamへログインしてください。

## 内容

- オフライン2人プレイと、招待制のオンライン入力同期。映像・音声は転送しません。
- 近い行動可能な自機への照準、独立した被弾・復帰、共有の予備機・ボム・パワー・得点。
- ボム・グレイズ・アイテムの重複処理防止、両者のホーミング・レーザー判定・会話・面移行への対応。
- TLS 1.3、証明書pinと256-bit参加鍵、入力・版・状態の検証、切断時の停止と所有ゲームの終了。

リリース番号は `v0.1.0`、協力ルールは `2`、通信プロトコルは `3` です。オンラインは双方が同じMODを使用してください。通常版1.00bとSteam版1.00bは相互接続でき、1.00aは1.00a同士で接続します。

## 検証範囲

3版×6装備、41件の境界診断と重要5件の追加確認、Extra・Practiceの開始と再挑戦、通常DLLでの同期とTLS通信を確認しました。通常版1.00bでは、診断用の無敵・火力強化と原作の時間進行を使い、通常1～6面のエンディングとExtraクリアまで到達しています。

通信試験は同一PCの分離プロセスによるループバックです。別PC・WAN、全難易度・全スペルの通しプレイは未検証のため、初回はPre-releaseとして配布します。自動NAT越え・中継サーバー・途中復帰・協力リプレイ保存は含みません。

詳細は [協力仕様](https://github.com/moyu1254/th12co-op/blob/v0.1.0/docs/cooperative-rules.md) と [検証結果](https://github.com/moyu1254/th12co-op/blob/v0.1.0/verification/RESULTS.md) を参照してください。
