# TH12 CO-OP v0.3.2

オンラインで相手の当たり判定マーカーと周囲の模様が残る問題を修正した **Pre-release** です。通信Protocol 4／協力Rules 6／ローカルIPC 1。両者とも本リリースを使用してください。

## 変更

- ホストは1P、参加者は2Pの当たり判定マーカーだけを表示します。相手の丸いマーカーと周囲の模様を両方とも非表示にします。
- 低速解除時の消去演出中も相手のマーカーを非表示に保ち、再び低速にした場合も適用します。
- v0.3.1のボム補充修正と、相手の自機本体を薄く描画する変更を維持します。低速移動、当たり判定、射撃、オプションは変更しません。

## 検証と制約

通常版1.00a・通常版1.00b・Steam版1.00bで、自分側のマーカーを表示し、相手側の丸と模様を非表示にする描画状態と同期ハッシュの一致を確認しました。使用バイナリ、その他の試験と未検証範囲は [v0.3.2の検証記録](../../verification/releases/v0.3.2.md) を参照してください。非表示・無音の隔離コピーで描画状態を読み取る試験であり、通常画面の目視評価、別PC／WAN、長時間の通しクリアを確認したものではありません。

## 使用方法

`TH12COOP-v0_3_2-Windows.zip` を展開し、`Start.cmd` または `Offline.cmd` を実行してください。各自が所有する対応版の原作が必要です。原作データ・セーブ・リプレイ・診断DLLは配布物に含みません。.NETランタイムは同梱しています。

同じリリースの `SHA256SUMS-v0.3.2.txt` でZIPのSHA-256を確認できます。GitHubの「Source code」ZIPには実行用バイナリを含みません。旧版のタグ・配布ZIPは保持しています。
