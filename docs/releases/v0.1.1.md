# TH12 CO-OP v0.1.1（協力ルール3）

Pre-releaseです。被弾直後のボム救済、同期不一致の検出、接続準備と停止処理を修正した更新です。2人が別々の自機を操作し、オフライン・オンラインで同じ協力ルールを使います。オンラインは入力を同期し、映像・音声は転送しません。

- 2Pのボムが、先に更新された1Pの受付期限だけを理由に救済へ間に合わなくなる境界フレームの問題を修正しました。両者の更新開始時の猶予を使い、確定済みのミスは取り消しません。
- 通常版1.00aの10億点以上の表示で、未初期化文字列を使う処理を修正しました。得点計算・上限は変更しません。
- 霊夢Aのビーム履歴、ECLの命令位置と並行処理、アイテム・UFO、敵弾の内部タイマーと運動パラメーター、レーザーの命令位置を同期検査へ追加しました。プロセスごとに異なるポインターは比較しません。
- 初期設定作成やセッション準備を中止・失敗した際に、途中のファイルが完成扱いで残る問題を修正しました。起動用に準備した資産とMODも再照合します。
- 準備中の切断を開始処理へ反映し、利用者の中止・通信切断・期限切れを区別します。終了処理によるabort理由の上書きと、診断保存の失敗が元の異常を隠す問題も修正しました。
- 正規のコントローラー入力を通信形式へ変換してから公開し、IPC・ネットワーク上の不正な入力ビットは引き続き拒否します。

敵HP、各自機の通常威力、UFOの吸収・報酬、共有予備機・ボム・パワー・得点、個別の被弾・復帰という基本ルールは維持しています。詳細は [協力仕様](../cooperative-rules.md) と [追加監査](../audit-followup.md) を参照してください。

対応する既知プロファイルは、通常版1.00a・通常版1.00b・Steam版1.00bです。通常版1.00bとSteam版1.00bは相互接続でき、1.00aは1.00a同士で接続します。1.00aと1.00bの混在は受け付けません。

**協力ルール3・通信プロトコル3・IPC構造体版1**。オンラインでは双方を同じv0.1.1へ更新してください。旧ルールの相手とは開始しません。

配布ZIPを展開し、`Start.cmd` を開いてください。オフライン専用の入口は `Offline.cmd` です。両者に対応する原作のコピーが必要で、ゲームデータは同梱しません。Steam版は原作を所有するアカウントでSteamへログインしてください。

使用バイナリ、実施した試験と残る範囲は [v0.1.1検証結果](../../verification/audit-v0.1.1/RESULTS.md) に記録します。通信確認は同一PCの分離プロセスによるもので、別PC・WANや全難易度・全スペルの完走を確認したリリースではありません。同期検査もゲーム内部の全状態を網羅するものではありません。
