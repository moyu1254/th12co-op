# TH12 CO-OP v0.4.0-rc.1（実回線試験用）

通信 Protocol 7、協力 Rules 6、ローカル IPC 1。ホストとゲストは同じ候補版を使います。v0.3.2（通信4）とは接続できません。

## 部屋番号で遊ぶ

1. 両方の Windows PC に `TH12COOP-v0_4_0-rc_1-Windows.zip` を展開します。各自が所有する対応版の原作と、グループで運用する合流サーバーが必要です。
2. 両端に同じ合流サーバーの URL を設定して `Start.cmd` を開きます。ホストが部屋を作成し、ゲストが6桁を入力します。
3. 照合画面に確立した経路が「直接 QUIC」または「WSS 中継」と表示されます。通話などで照合コードの一致を確認し、双方で承認するとゲームが始まります。

運用者は `TH12COOP-Rendezvous-v0_4_0-rc_1.zip` の合流サーバーを ASP.NET Core Runtime 10 で起動できます。同じホスト名で有効な証明書と HTTPS/WSS、STUN（UDP 3478）を用意してください。公式の公開サーバーはありません。従来の手入力による直接 TCP 接続も選べます。[運用手順](../rendezvous.md)

## 検証範囲

同一 PC の Steam 版 1.00b 同士で、直接 QUIC・WSS 中継ともにステージ到達を確認しました。各60秒、通信エラーは0件でした。

別 PC・同一 LAN、実ルーターの UPnP、別回線の WAN は未検証です。試験時は両端の経路表示、照合、ステージ到達、UPnP 転送の追加・解放を記録してください。[候補版の検証結果](../../verification/releases/v0.4.0-rc.1.md)・[接続環境の記録欄](../../verification/phase3-relay.md#別-pc-での検証手順と記録欄)
