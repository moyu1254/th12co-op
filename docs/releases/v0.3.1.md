# TH12 CO-OP v0.3.1

被弾後のボム補充修正と、オンラインの視認性改善を含む **Pre-release** です。通信Protocol 4／協力Rules 6。v0.3.0以前とは接続できないため、両者とも本リリースを使用してください。

## 変更

- 死亡復帰時の補充を止めていたフックを削除しました。1P・2Pとも、復帰時に共有ボムが2個未満なら原作の処理で2個に補充します。2個以上の在庫とかけらは保持します。残機がなく待機する間は補充せず、エクステンドで復帰した時に補充します。
- オンラインでは自分の当たり判定マーカーだけを表示します。ホストは1P、参加者は2Pのマーカーを残します。
- 相手の自機本体の不透明度を原作の約44%にします。自分の自機、弾、オプション、ボムの描画と判定は維持します。オフラインでは両者のマーカーを表示します。
- 表示の違いは描画時だけ適用します。ゲーム入力や共有状態には加えず、低速移動や当たり判定を変更しません。

## 検証と制約

今回の実ゲーム検証対象はSteam版1.00bです。無音・非表示の隔離コピーを使用し、原作インストールは変更しません。実施した試験、配布バイナリの指紋、未検証範囲は [v0.3.1の検証記録](../../verification/releases/v0.3.1.md) を参照してください。

通常版1.00a／1.00bでの今回の変更の実行、通常画面の目視評価、別PC／WAN、物理パッド、長時間通しクリアは未検証です。以前のリリースの検証を今回の修正の合格証拠として扱いません。

## 使用方法

`TH12COOP-v0_3_1-Windows.zip` を展開し、`Start.cmd` または `Offline.cmd` を実行してください。起動中の旧ランチャーは終了してから新版を起動してください。各自が所有する対応版の原作が必要です。原作データ・セーブ・リプレイ・診断DLLは配布物に含みません。.NETランタイムは同梱しています。

同じリリースの `SHA256SUMS-v0.3.1.txt` でZIPのSHA-256を確認できます。GitHubの「Source code」ZIPには実行用バイナリを含みません。旧版のタグ・配布ZIPは保持しています。
