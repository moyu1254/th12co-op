# TH12 CO-OP v0.3.0

協力ショット補正、接続後のゲーム内自機選択、ゲーム設定画面の停止修正を含む **Pre-release** です。通信Protocol 4／協力Rules 5。v0.2.0 / Rules 4とは接続できません。双方で本リリースを使用してください。旧版のタグ・配布物は保持しています。

## 変更

- ボス通常・スペル・中ボスは120%/60フレーム、通常敵全体は125%/30フレーム、UFOは100%/30フレームを初期値として、実命中したショットを補正します。
- 同一フレームの全対象の命中から倍率を確定し、対象の処理順による初撃の未補正を防ぎます。端数を蓄積し、片方が行動不能になったら倍率を直ちに1へ戻します。ボム単独の場合の原作ダメージは維持します。
- 原作のキャラクター・装備画面を使い、接続後に1P、2Pの順で各自が機体と装備を選びます。オフライン、オンライン、Normal／Practice／Extraに対応します。
- 「ゲーム設定」の停止原因だったUIスレッドの非同期読込の同期待ちを除去しました。読込・表示・変更・保存・再読込と、無関係な設定項目の保持を検証しています。

## 検証と制約

通常1.00a／1.00b／Steam1.00bの隔離コピーで、無音・非表示の実ゲーム検証を行いました。通常1.00b／Steam間で6,622フレームの同期が一致し、ボス通常・スペル・道中の実命中から求めた倍率を独立した計算と照合しました。UFO、オフライン、別装備、キャンセル、リトライ・再入場、原作デモも対象です。ランチャー自己テスト19群、管理コード回帰18群が通過しています。

指定の履歴式は、命中量が急変した際の瞬間火力を厳密に制限する式ではありません。また協力時は、敵生成中のショット命中を通常の敵更新まで保留するため、生成直後の撃破タイミングが原作と異なる場合があります。原作との撃破時間・早回し・弾幕量・UFO弾消しの定量比較、全装備／Power／全スペル、別PC／WAN、通常画面の視認性、物理パッド、長時間通しクリアは未検証です。初期倍率の難易度調整が完了した安定版とは扱いません。

詳しい実施範囲は同梱の [Rules 5検証](../../verification/rules5/RESULTS.md)、配布ビルドの記録は [リリース検証](../../verification/releases/v0.3.0.md) を参照してください。CIの成功を実ゲームやWANの動作確認とは扱いません。

## 使用方法

`TH12COOP-v0_3_0-Windows.zip` を展開し、`Start.cmd` または `Offline.cmd` を実行してください。起動中の旧ランチャーは終了してから新版を起動してください。各自が所有する対応版の原作が必要です。原作データ・セーブ・リプレイ・診断DLLは配布物に含みません。.NETランタイムは同梱しています。

同じリリースに添付する `SHA256SUMS-v0.3.0.txt` でZIPのSHA-256を確認できます。GitHubの「Source code」ZIPには実行用バイナリを含みません。
