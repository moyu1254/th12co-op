# 2人協力プレイの仕様

この文書はv0.3.2の協力プレイルール6を定義する。v0.3.1もルール6、旧版v0.3.0はルール5、v0.2.0はルール4。実行した試験と確認範囲は [検証結果](../verification/RESULTS.md) を参照。

## 自機と敵

- 自機は2体。霊夢・魔理沙・早苗のA/Bを各自が選択し、移動速度、低速、射撃、オプション、被弾、復帰、当たり判定、アニメーションをそれぞれ処理する。接続後の原作の選択画面を1P、2Pの順に使い、それぞれ自分の入力で選ぶ。確定入力と選択状態を同期する。
- 自機同士は重なれる。押し合いや、味方のショット・ボムによる被弾は追加しない。
- オンラインでは自分の当たり判定マーカーだけを表示する。相手の丸いマーカーと周囲の模様は、低速解除時の消去演出を含めて表示しない。オフラインでは両方を表示する。
- 自機狙いは、その敵または発射位置に近い、行動可能な自機を対象とする。同じ距離なら1Pを選ぶ。一連のECL処理・斉射では対象を固定し、既に撃たれた直進弾の向きは後から変えない。
- 原作の再照準命令が実行された場合は、その時点で対象を選び直す。片方が死亡・復帰待ちなら、もう片方を狙う。両方が対象外の短い遷移中は1Pの座標を参照する。
- 弾数、配置、速度、敵の耐久力、ステージ進行速度は原作の設定を使う。自機が増えたことだけを理由に敵や弾幕の更新回数を増やさない。
- 自機の近くで弾を出さない原作の判定は、両方の行動可能な自機について成立する。
- ショットは原作の制限を適用後、両者の有効命中履歴で補正する。ボス通常・スペル・中ボスは60フレームで120%、道中全体は30フレームで125%、UFOは30フレームで100%を初期目標とする。片方が行動不能なら倍率1。ボム・弾消しは補正しない。式と同一フレーム集計は[火力設計](cooperative-damage.md)を参照。ホーミングの対象と、敵を破棄するときの参照解除も自機ごとに扱う。
- 自機を押す・引く原作の強制移動処理が呼ばれた場合、行動可能な両自機へ個別に適用する。同じ処理内の共有弾の更新は1回に保つ。

## 被弾・残機・ボム

- 画面の残機数はチーム共通の予備機数。被弾時に予備機があれば1機を消費し、その自機の復帰を確保する。
- 予備機がない場合、被弾した自機は非表示で待機する。相方はそのまま続行する。両方が復帰不能になり、原作の被弾演出時間が経過した時にゲームオーバーとなる。
- エクステンドは待機中の自機の復帰に優先して使う。両方が待機中なら1Pから復帰し、待機中の自機がなければ予備機として蓄える。
- 次ステージへの移行はチェックポイントとし、両方が復帰する。リトライ・コンティニュー・新規開始は原作の初期化を両方に適用する。
- ボムは共有。在庫を1つ消費して1回発動し、ダメージを二重に加算しない。発動者の位置・効果を使い、行動中の両方を保護する。
- 同フレームのボム要求は固定更新順により1P優先。原作の被弾直後のボム受付時間内なら、相方のボムも救済として扱う。受付期限は両者の更新開始時にそろえ、1Pの更新が先に進んだことだけで2P発動時の救済を失わない。確定済みのミスは取り消さない。
- 被弾した自機が復帰するとき、共有ボムが2個未満なら原作の処理で2個に補充する。2個以上の在庫とかけらは保持する。残機がなく復帰待ちの場合は補充しない。待機後にエクステンドで復帰する場合も同じ処理を行う。開始・リトライ・コンティニュー時の初期数、アイテムによる補充は原作どおり。
- 同じ弾が同時に両者へ接触した場合は両者を判定する。レーザーの被弾時消去は実際に被弾した自機の周辺で行う。
- グレイズはチーム共通。同じ弾・原作のレーザー判定間隔に対する加点は1回とし、2人重なっての二重加点を行わない。演出は実際にかすった自機の位置に出す。

## アイテム・得点・進行

- パワー、得点、点符価値、グレイズ、UFO収集、残機・ボムのかけらは共有。同じアイテムを二重取得しない。
- どちらかが上部回収ラインを越えれば通常アイテムを回収できる。低速時の吸引範囲は各自の低速入力で決める。
- 回収中のアイテムは対象を固定し、2人の間を往復しない。対象が死亡・待機になった場合は生存者へ引き継ぐ。実際に接触している自機がいれば、その取得を優先する。
- UFOの色変更停止などの近接判定も行動可能な自機を対象とする。UFOの生成・破壊・報酬処理はチームで1回。
- 時間経過に伴う内部ランクの更新は1回。各被弾による原作のランク・パワー・スペル取得失敗などの影響は共有プレイへ反映する。
- 会話・ポーズ・ステージ遷移・ボス進行は共通。会話による自機の制御・オプション表示の切替は両方へ適用する。
- 協力モードでは全装備のExtraと全6ステージのPracticeを選べる。メニューの選択可否だけを変更し、原作のクリア記録を偽造しない。オンラインも同じ選択肢から開始できる。
- HUDが自機に重なる場合の表示調整は両方を考慮する。共有メニュー、キャラクター会話、チームへのヒントは1つだけ表示する。
- エンディングとクリア判定はチームで1回。1Pの機体・装備と共通のコンティニュー回数を原作の分岐へ渡す。オンラインは開始ごとに新しい作業コピーを使い、過去の協力スコアやクリア記録を読み戻さない。
- 原作インストールと分離した作業コピーで記録する。原作形式は入力を1人分しか保存しないため協力プレイのリプレイ保存は行わない。原作のデモ・リプレイ再生は1人用の処理を保つ。

## オンライン

オフラインとオンラインに同じルールを適用する。オンラインでは1Pがホスト、2Pが招待された参加者となる。各PCでゲームを実行し、確定した入力を同期する。映像・音声は転送しない。

オンラインでは各PCの自分の当たり判定マーカーだけを表示する。相手の自機本体は原作の不透明度に112/255を掛けて描画し、自分の自機は原作の不透明度を維持する。この表示差は描画時だけ適用し、判定・低速移動・アニメーション更新・同期状態は変更しない。オフラインでは両者のマーカーと不透明度を維持する。

復帰権やアイテムの回収先、機体選択、火力履歴・端数などMODが追加した状態も不一致の検出対象に含める。開始前にルール番号6とMODファイルの一致を確認し、旧ルールの相手とは開始しない。

ルール3では猶予の境界フレームの非対称性と、状態検査の不足を修正した。敵HP、各自機の威力、UFOの吸収・報酬、共有資源の基本ルールは変更していない。

ルール4では各自の機体・装備を独立させ、発動した自機の装備でボムを処理する。各PCの入力・表示・音量はローカルに保存し、確定した操作だけを同期する。フレームスキップ等のゲーム進行設定は共通化する。

ルール5では有効なショットだけに区分別の協力補正を加え、機体選択を接続後のゲーム内画面へ移す。通信形式はProtocol 4を維持する。

ルール6では死亡復帰時のボム補充を止めていたフックを削除し、原作の補充処理を復元する。1P・2Pとも同じ経路を通る。通信形式はProtocol 4を維持する。
