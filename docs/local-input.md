# 各PCの入力設定

ランチャーの「入力設定」で、1P / オンラインの自分と、オフライン2Pの割り当てを保存する。保存先は `%LOCALAPPDATA%/TH12Coop/input.json`。元の `th12.cfg` とセーブは変更しない。設定はこのPCだけで使い、入力デバイス名やキー番号を通信しない。

キーボードの各ボタンをクリックしてキーを押すと割り当てられる。右クリックの「割当なし」で解除する。パッドはデバイスを選択し、各操作のボタン番号、左右・上下の軸、軸反転、デッドゾーン、十字キー / POVを指定する。ボタンは1始まり。XInputを選択した場合はA/B/X/Yなどの名前も表示する。キーボードとパッドは同時に利用できる。

入力はゲームが前面にある間だけ読み取る。別アプリへ切り替えた際は中立入力にする。キー入力の注入、カーソル移動、振動、デバイスの排他取得を行わない。パッドが切断された際もキーボードは使える。切断時に別のパッドへ自動的に切り替えず、選択したデバイスを1秒間隔で再確認する。

## 対応API

* XInput: Windowsの4つのユーザースロットから選択。左右スティック、十字キー、10ボタン、左右トリガーに対応する。トリガーは30を超えると押下扱い。
* Windows Multimedia joystick: Windowsが公開する最大16スロットの汎用USBパッド。最大6軸・32ボタン・POVを取得する。ドライバーが公開する最小値・最大値で軸を正規化し、存在しない軸は中立にする。

同じXboxパッドが両APIに表示される場合はXInput側を選択する。XInputのスロット、USBパッドのWindows番号は接続順によって変わることがある。接続順を変えた後は「再検索」で対象を確認する。USB側では番号に加えてメーカー・製品・ドライバー識別を照合し、別機種へ入れ替わった場合に入力を引き継がない。同型機の個体識別はこれらのAPIでは保証されない。

ドライバーがこのどちらのAPIにも公開しないデバイスや32個を超えるUSBボタンは対象外。実物のパッドでの接続・切断・再接続、BluetoothとUSBの違いは別途実機確認が必要。

## ゲーム・通信との境界

`LocalInputReader` は設定をセッション開始時に固定し、`InputComposer` が以下の原作操作マスクを作る。

| 操作 | ビット |
|---|---|
| ショット / 決定 | `0x01` |
| ボム / 戻る | `0x02` |
| 低速 | `0x08` |
| 上・下・左・右 | `0x10`・`0x20`・`0x40`・`0x80` |
| ポーズ | `0x100` |

アナログ軸はデッドゾーンを超えた方向を原作のデジタル操作へ変換する。斜め移動の速度補正は原作の自機更新が行う。POVは8方向へ丸める。キーボード・スティック・十字キー・割り当てボタンを合わせた後に、上下同時・左右同時をそれぞれ中立へ正規化する。

オンラインはネイティブのフレーム要求を確認した後にそのPCの入力を1回サンプルし、遅延フレームへ登録する。ホストとゲストに同じパッド設定を要求せず、確定した操作マスクだけを既存の入力同期で送る。テスト用の `NetBridge` は入力設定が渡されない場合に従来のIPC読み取りを保持するため、自己テストは実デバイスを読まない。

オフラインは同じ入力リーダーを使って既存の2人分の共有入力へ渡す。メニュー操作とポーズは1P、オンラインのゲーム中ポーズは両者の入力を受け付ける。原作デモ・リプレイの1人用処理は維持する。

## 検証

`LocalInputTests.cs` は実デバイスやWindowsの入力状態に触れず、正規化境界を試験する。キーボードとパッドの併用、再割当、32番ボタン、6軸、反転、デッドゾーンの境界、POV全8方向と中立、逆方向同時入力、非アクティブ時の無入力、切断時のキーボード継続、設定の往復保存と不正値拒否を含む。試験の実施結果は [検証記録](../verification/RESULTS.md) を参照。

APIの根拠はMicrosoftの [XInputガイド](https://learn.microsoft.com/en-us/windows/win32/xinput/getting-started-with-xinput)、[joyGetPosEx](https://learn.microsoft.com/en-us/windows/win32/api/joystickapi/nf-joystickapi-joygetposex)、[JOYINFOEX](https://learn.microsoft.com/en-us/windows/win32/api/joystickapi/ns-joystickapi-joyinfoex)、[JOYCAPSW](https://learn.microsoft.com/en-us/windows/win32/api/joystickapi/ns-joystickapi-joycapsw)。TH12への接続位置は [エンジン接続](native-engine.md) を参照。
