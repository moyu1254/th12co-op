# 東方星蓮船 CO-OP

TH12の **通常版1.00a・通常版1.00b・Steam版1.00b** で、2人が別々の自機を操作するWindows用MODです。オンラインはWindows 11以降のTLS 1.3対応環境を使用します。実機での確認範囲は [検証結果](verification/RESULTS.md) に記録しています。

バージョンは **0.3.2（Pre-release / Rules 6）** です。オンラインで相手の当たり判定マーカーと周囲の模様が残る問題を修正しました。被弾後のボム補充と相手の自機を薄くする変更も含みます。双方で同じリリースを使用してください。旧版のタグ・ZIPは保持しています。

[ダウンロード](https://github.com/moyu1254/th12co-op/releases/tag/v0.3.2) · [ドキュメント](docs/README.md) · [不具合報告・開発への参加](CONTRIBUTING.md) · [MIT License](LICENSE)

別PC／WAN、物理ゲームパッドの操作・再接続、全機体の組み合わせでの全編クリア、原作との撃破時間・早回しの定量比較は未検証です。確認済みの範囲と火力補正の制約は [Rules 5の検証結果](verification/rules5/RESULTS.md) を参照してください。

## 起動

[GitHub Releases](https://github.com/moyu1254/th12co-op/releases) から配布ZIPをダウンロードして展開します。GitHubの「Source code」ZIPには実行用バイナリを含みません。

同じリリースにある `SHA256SUMS-v0.3.2.txt` と、ダウンロードしたZIPのSHA-256を照合できます。

```powershell
Get-FileHash .\TH12COOP-v0_3_2-Windows.zip -Algorithm SHA256
```

- `Offline.cmd`：このPCで2人プレイを開始。
- `Start.cmd`：オフライン、オンラインの部屋作成、オンライン参加を選択。

ランチャーの「ゲーム」で使用する原作のバージョンを選択します。通常のインストール先とSteamライブラリは自動検索され、プレイ開始時にMOD用のコピーが作られます。見つからない場合は「参照」から `th12.exe` のあるフォルダーを選択してください。Steam版ではあらかじめSteamを起動し、TH12を所有するアカウントでログインしておきます。

TH12を別に起動している場合は、先に終了してください。原作の多重起動制限に合わせ、ランチャーが重複起動を止めます。

原作が使用する32bit版DirectX補助ランタイム（`d3dx9_40.dll`）が必要です。オンラインでは両方のPCに用意してください。Windowsにインストールされたもの、または原作フォルダー内の同DLLを利用できます。必要な場合は[MicrosoftのDirectX End-User Runtimes](https://www.microsoft.com/en-us/download/details.aspx?id=8109)を使用してください。.NETランタイムは配布ZIPに同梱しています。

接続後の原作の機体・装備画面で、1P、2Pの順に霊夢・魔理沙・早苗のA/Bを選びます。画面の1P／2Pに従い、それぞれ自分の入力で決定・取消します。難易度・Practice開始面は1Pが選択します。

移動速度・当たり判定・ショット・オプション・ボムの種類・アニメーションは自機ごとに処理します。**予備機・ボム在庫・パワー・スコア・ベントラーはチームで共有**です。予備機がない状態で被弾した自機は復帰を待ち、相方は続行できます。エクステンドは待機中の自機の復帰に優先して使います。

ボムは発動した自機の装備でチーム1回分を発動します。被弾後の復帰時に共有ボムが2個未満なら、原作どおり2個へ補充します。2個以上の在庫とかけらは保持し、残機がなく待機する間は補充しません。オンラインでは自分の当たり判定マーカーだけを表示し、相手の自機を薄く描画します。会話・エンディングは1Pの機体を使います。

ショットの合計火力は、実際の命中履歴によりボス通常・スペル・中ボス120%、道中全体125%、UFO100%を初期目標として補正します。片方だけが攻撃する場合は原作相当、行動不能時は直ちに倍率1へ戻ります。ボムと弾消しは維持します。式と検証範囲は[火力設計](docs/cooperative-damage.md)を参照してください。

自機狙いは近い行動可能な自機を対象とし、斉射中は対象を固定します。グレイズとアイテムの加点は重複させず、各自の低速吸引と上部回収を使えます。回収中のアイテムは対象を固定し、対象が死亡・待機になった場合は相方へ引き継ぎます。詳しい仕様は [協力プレイのルール](docs/cooperative-rules.md) を参照してください。

協力プレイではExtraの全機体・装備と、通常4難易度のPractice全6面を選択できます。メニューの選択可否だけを変更し、元のクリア記録は書き換えません。

原作のリプレイには2Pの入力を保存できないため、協力プレイのリプレイ保存は無効です。原作のデモ・リプレイ再生は1人用の処理を保ちます。

| 操作 | オフライン 1P | オフライン 2P | オンラインの自分 |
|---|---|---|---|
| 移動 | ↑ ↓ ← → | I K J L | ↑ ↓ ← → |
| ショット | Z | F | Z |
| ボム | X | G | X |
| 低速 | 左Shift | D | 左Shift |
| ポーズ | Esc | 1Pが操作 | プレイ中は両者ともEsc |

ゲームウィンドウを選択して操作します。同一キーボードの同時押し数はキーボード側の制限も受けます。

「入力設定」でキーボードとゲームパッドの割当を変更できます。XInputとWindowsジョイスティックに対応し、デバイス、各ボタン、アナログ軸、デッドゾーン、十字キーを選べます。キーボードとパッドは併用でき、オンラインでは各PCの入力をそれぞれの自機へ送ります。ゲームが選択されていない間は入力しません。詳細は[入力設定](docs/local-input.md)を参照してください。

「ゲーム設定」で選んだ画面方式・解像度・BGM／効果音の音量は各PCに保存されます。オンラインではフレームスキップなどゲームの進行に影響する項目だけを共通の設定にします。元の設定とオフラインの進行設定は維持します。対象項目は [設定の分離](docs/local-configuration.md) に記載しています。

## オンライン

**両方のPCで原作を実行し、フレーム番号付きの操作入力を同期します。映像と音声は送受信しません。** 描画と音声再生は各PCのゲームが行います。両者の入力がそろってから進むため、回線の遅延が大きい場合は操作の遅れや待ち時間が生じます。

1. ホストで `Start.cmd` →「オンライン · 部屋を作成」。
2. ホストのIP、ポート、ルームコードを相手へ伝え、「部屋を作成」。
3. ゲストで `Start.cmd` →「オンライン · 部屋に参加」。同じ情報を入力して「参加」。
4. ゲーム本体・MOD・設定の一致を確認後、両方のゲームが起動します。ホストがステージを選択します。

通常版1.00bとSteam版1.00bは相互に接続できます。1.00aは1.00a同士で接続します。

このリリースの協力ルール番号は **5**、通信番号は **4** です。MOD・ルール番号・共通設定・データ・ローカルのDirectX補助DLLの構成は両者で一致させてください。画面・音量・入力設定は異なっていて構いません。旧ルールのMODや `T12L3` 以前のルームコードは利用できません。

標準ポートは **TCP 3012** です。同じLANではホストのLANアドレスを使います。インターネットでは到達可能なVPNアドレス、またはホストのルーターで転送したTCPポートを使います。Windowsファイアウォールでも接続を許可してください。部屋検索・中継サーバー・自動NAT越えは含みません。VPNや任意の外部中継の選択肢は [通信セキュリティ設計](docs/network-security-design.md) にまとめています。

相手には同じリリースの配布ZIPを渡します。**ホスト・ゲストとも対応する原作のコピーが必要です。** 各PCでZIPを展開して `Start.cmd` を開き、使用するゲームを選択します。ZIPには原作のゲームデータを含めていません。

コマンドで準備する場合は、ZIPを展開したフォルダーでPowerShellを開き、原作の場所を指定します。Windows標準のPowerShell 5.1とPowerShell 7に対応します。

```powershell
.\scripts\Prepare-Game.ps1 -OriginalGame 'C:\Program Files (x86)\上海アリス幻樂団\東方星蓮船'
```

ルームコードには部屋の証明書の指紋と256-bitの参加鍵を含みます。通信はTLS 1.3で保護され、入力の役割・順番・長さ・使用可能な操作を検証します。コードは参加させる相手だけに伝えてください。

信頼境界・想定する攻撃・対策と残る制約は [脅威モデル](docs/TH12CO-OP-threat-model.md) に記録しています。

通信断、入力の欠落、ゲーム状態の不一致があれば進行を止め、セッションのゲームを終了します。途中復帰はありません。オンラインでは毎回同じ進行設定と新規スコアで始め、画面・音量・入力設定だけを各PCから引き継ぎます。

## ゲーム本体

| 対応する製品版 | MOD用フォルダー | オンライン互換 |
|---|---|---|
| 通常版1.00a | `game/` | 通常版1.00a |
| 通常版1.00b | `game-retail-1.00b/` | 通常版・Steam版1.00b |
| Steam版1.00b | `game-steam-1.00b/` | 通常版・Steam版1.00b |

実行ファイルとデータは既知のSHA-256で識別します。対応指紋とアドレスの比較は [バージョン検証](docs/version-layout-audit.md) を参照してください。体験版、他MODで改変済みのEXE、未確認の将来版は対象外です。

元のインストール先は書き換えません。MODのスコアと設定は専用コピー内に作られます。ゲームEXEはディスク上で改変せず、オフライン・オンラインとも停止状態で起動して、ゲームの初期化前に専用DLLを接続します。起動中のゲームへ後から適用する操作は提供しません。

Steam版は専用コピーにTH12のApp IDを設定し、正規のSteam起動処理を通します。両モードともゲームコードが読み込まれた直後、最初の乱数初期化より前に接続します。展開済みの実行ファイルを作成・配布する処理はありません。

## ビルド・検証

開発と配布は [moyu1254/th12co-op](https://github.com/moyu1254/th12co-op) で管理します。取得・検証・リリースの手順は [開発ガイド](docs/development.md) を参照してください。

必要な環境はVisual Studio C++ Build Tools（x86）、Windows SDK、.NET 10 SDK、PowerShellです。自己完結版は.NET 10 LTSのランタイムを同梱します。

```powershell
git clone https://github.com/moyu1254/th12co-op.git
cd th12co-op
.\scripts\Test-Repository.ps1
.\build.ps1 -SelfContained
.\scripts\Test-Repository.ps1 -RunSelfTest
```

ビルドと自己テストに原作データは不要です。ソースを取得するブランチとバージョン別の検証記録は [開発ガイド](docs/development.md) で確認してください。

実ゲーム検証用の `th12coop-smoke.dll` は通常DLLと別ファイルです。メニュー入力の自動化に加え、資源・衝突・アイテムなどの境界条件を作る診断機能を含みます。入力だけで操作する試験と、ゲーム内状態を意図的に変更する診断試験は区別しています。診断には破棄可能な専用コピーを使い、通常プレイ用フォルダーでは実行しないでください。通常DLLにはこの診断用インターフェースを含めず、オンライン入力は認証済みセッションの確定フレームに限って適用します。

```powershell
.\build.ps1 -NativeOnly -SmokeTest
```

`src/native` は原作の自機生成・更新・描画・衝突処理とフレーム同期への接続です。`src/injector` は対応EXEの指紋を確認する32bitローダーです。`src/launcher` はランチャー・入力管理・TLS通信・同期確認を担当します。

実装の説明は [エンジン接続](docs/native-engine.md)、共有メモリの仕様は [Native IPC](docs/native-ipc.md) を参照してください。実施済みの試験、使用バイナリと残る制約は [検証結果](verification/RESULTS.md) に集約します。診断用の無敵・火力強化による面進行確認を、通常難易度でのクリア実績とは扱いません。
