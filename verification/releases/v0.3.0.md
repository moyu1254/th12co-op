# v0.3.0 リリース検証

実施日: 2026-10-30。Pre-release / 通信4 / 協力ルール5 / ローカルIPC 1。製品版番号を0.3.0へ更新し、ランタイム同梱のランチャーを再ビルドした。ゲーム処理を変更する追加修正は行っていない。

製品DLLとinjectorのSHA-256が [Rules 5実ゲーム検証](../rules5/results.json) と一致することを確認した。前の記録のランチャーは版番号更新前の開発ビルドであり、配布する0.3.0の指紋・再実行結果は [v0.3.0.json](v0.3.0.json) に分ける。

| 検証 | 結果 |
|---|---|
| ランタイム同梱ランチャーのビルド | `build.ps1 -LauncherOnly -SelfContained` 成功。製品番号0.3.0、.NET 10.0.14、win-x64 |
| リリース用ランチャー自己テスト | 19群合格。STA設定画面の読込・変更・保存・再生成、実TLS、旧ルール拒否を含む |
| 管理コード回帰 | 18群合格 |
| 製品DLL・injectorの継続使用 | 先の実ゲーム検証とバイト単位で一致。再コンパイルやCI生成物への差替えを行わない |
| 配布候補ZIPの検査 | 724ファイルの内容一致、ZIP構造・CRC、PEと同梱ランタイム、原作・診断DLL・秘密情報の代表的形式の混入検査が合格 |
| 配布候補を展開したランチャー | 展開後のバイナリ一致、自己テスト19群・管理コード回帰18群が合格。原作を起動しない検証 |
| リリース用ランチャーでの実TLS | 通常1.00a同士、接続後のゲーム内選択、60秒の入力同期と双方の移動・射撃、正常終了、無音・非表示を確認。ワークスペースのテストガードを使用し、診断DLLは配布しない |

配布ZIPの検査には `scripts/verify_package.py` を使用し、Git追跡ソース・検証記録との一致、ZIP構造とCRC、ランタイムとPE構造、診断DLL・原作データ・認証情報の混入がないことを検査する。公開するZIPのSHA-256は、同じGitHub Releaseの `SHA256SUMS-v0.3.0.txt` に添付する。自己参照を避けるため、ZIP自身のハッシュをZIP内の検証記録へ埋め込まない。

実ゲームの難易度・履歴式・生成直後の命中時刻に関する制約、別PC／WANなどの未検証範囲は [Rules 5の検証記録](../rules5/RESULTS.md) と [リリースノート](../../docs/releases/v0.3.0.md) を引き継ぐ。CIはソースのビルド・自動テストであり、実ゲーム・WANの確認とは扱わない。旧タグ・旧リリースを置き換えない。
