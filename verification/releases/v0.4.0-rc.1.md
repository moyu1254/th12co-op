# v0.4.0-rc.1 の検証

2026-11-16、Windows 11 Pro（build 26200）、.NET SDK 10.0.403。通信 Protocol 7、協力 Rules 6、ローカル IPC 1。ランチャーと合流サーバーの[ビルド対象コミット](https://github.com/moyu1254/th12co-op/commit/523301aa3cc48f46f57b486cfa793d6f44412a49)を以下のバイナリで検証した。

## Steam 版 1.00b 同士の実ゲーム

同一 PC の隔離コピー2つを、IPv4 ループバック上の部屋番号で接続した。ホスト・ゲストとも経路と照合コードを試験プログラムで確認し、自動承認の後、両方がステージに到達した。各端末のゲームが無音・非表示で動作し、試験後に終了したことも確認した。確認フレームは停止時点の値。

| 経路 | ホストの確認フレーム | ゲストの確認フレーム | 試験時間 | 通信エラー |
|---|---:|---:|---:|---:|
| 直接 QUIC | 3,276 | 3,276 | 60秒 | 0 |
| WSS 中継（ゲストの IP 証明なし） | 3,379 | 3,379 | 60秒 | 0 |

`build.ps1 -SelfContained` と `build.ps1 -NativeOnly -SmokeTest` の後、[Phase 3 の再現手順](../phase3-relay.md#再現手順)にある結合試験の出力に、配布候補の `TH12Coop.dll`、`Keryx.Ice.dll` とネイティブファイルを配置した。上表は、運用者用 ZIP から展開した `TH12Coop.Rendezvous.dll` も同じ出力に配置し、Steam 版の2つの専用コピーを `--games` と `--relay-games` に渡した結果。ゲームの準備・入力は試験プログラムが行った。

ランチャー自己テスト23グループ（managed 回帰19グループを含む）、合流サーバーの自己テスト、部屋番号の直接・中継の結合試験、配布処理の回帰6件が成功した。
