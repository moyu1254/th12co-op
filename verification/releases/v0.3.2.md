# v0.3.2 配布バイナリ検証

2026-10-30。v0.3.1を取り込み、当たり判定マーカーの丸と周囲の模様を相手側だけ非表示にする修正を追加。通信4・協力ルール6・IPC 1を維持する。原作インストール、既存リリース・タグは変更しない。

## ビルド

`build.ps1 -SelfContained` と `build.ps1 -NativeOnly -SmokeTest` が成功。damage-budget、fiber-FPU、quiet-guardの自己テストが成功。ランチャー自己テスト19グループ、管理側回帰19グループ、配布処理回帰5件が成功した。使用した配布DLL・ランチャー・インジェクター・ランタイムの指紋は [JSON](v0.3.2.json) を参照。

以前の試作時にはWindows セキュリティによるインジェクター隔離があったが、今回の通常ビルドと下記の実ゲーム試験は成功。セキュリティ設定や除外は変更していない。旧試作の記録は [履歴](../focus-markers/RESULTS.md) と区別する。

## 実ゲーム

製品DLLを不可視・無音の用途別隔離コピーへ導入し、入力IPCで進行させた。状態変更用の診断DLLは使用していない。

| 試験 | 対象 | 結果 |
| --- | --- | --- |
| 当たり判定マーカーのANM 76/77 | 通常1.00a：霊夢A／早苗A | PASS、787同期フレーム一致 |
| 同上 | 通常1.00b：霊夢B／魔理沙B | PASS、787同期フレーム一致 |
| 同上 | Steam1.00b：魔理沙A／早苗B | PASS、787同期フレーム一致 |
| マーカー描画数・相手の自機の不透明度 | 通常1.00a、両方のローカル役割 | PASS、1048同期フレーム一致 |
| ランチャーからのTLS入力同期 | 通常1.00bホスト／Steam1.00bゲスト、60秒 | PASS、役割1/2のIPC伝達も確認 |
| ランチャーからのオフライン起動 | 通常1.00b | PASS |

マーカー試験は、自分側の76/77の可視状態、相手側の76/77の非可視状態、低速解除直後4フレーム×3回、再低速×3回、原作どおりのANM消滅、片方ずつの低速を確認した。別アニメーションである周囲の模様も生成時に同じ描画抑止を受けるため、親マーカーのIDが消去された後も相手側だけ非表示が続く。

全実ゲーム試験でquiet制御と所有ゲームの終了を確認。ランチャー試験では元コピーの設定・スコアを保持した。

## 配布と未検証範囲

`Package.ps1` と `verify_package.py` で追跡ソースとの一致、ZIP CRC、x86製品DLL／インジェクター、x64ランチャー、.NET 10.0.14同梱、原作データ・診断DLL・秘密情報の除外を確認してから公開する。ZIPとSHA-256一覧を同じGitHub Releaseへ添付する。CIの結果は対象コミットに結び付けて確認する。

ANMリストと可視ビット、描画観測の読み取りによる検証であり、通常表示のスクリーンショット・目視品質、別PC／WAN、物理パッド、長時間通しクリアは未検証。オフラインのマーカー描画と、被弾・復帰やステージ移行を含む長時間の表示推移は今回個別に試験していない。以前のリリースで確認した範囲を新版の合格証拠に置き換えない。
